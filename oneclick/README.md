# Edge Drop 151 双击回退工具

## 已有环境反馈

2026-10-25，使用者提供的环境为 **Windows 11 家庭版、Edge 151.0.4129.107**，反馈实际回退后目前使用无问题，Drop 仍能正常传输。该反馈来自之前实际执行的回退过程；不是本双击工具已经完成全流程测试的结论，不推广为其他设备或未来日期的保证。

> **实验版：尚未通过真实系统全流程测试，请勿当作稳定的一键修复工具。** 已完成语法及基础逻辑检查；尚待隔离环境验证备份、真实安装、失败恢复和更新状态恢复。旧版 Edge 有安全风险，本工具不保证 Drop 持续可用或永久锁版。

## 用法

1. 完整解压本文件夹到本地磁盘，不要在 ZIP 里运行。
2. 把自己下载的 `MicrosoftEdgeEnterpriseX64.msi` 放在本文件夹，和 `Start-Rollback.cmd` 同级。
3. 保存工作，退出所有 Edge 窗口及后台进程。
4. 双击 `Start-Rollback.cmd`，同意管理员权限，阅读提示后输入 `YES`。
5. 等待备份、安装和文件版本检查结束。启动 Edge，访问 `edge://version` 验证运行版本并测试 Drop。
6. 测试结束双击 `Restore-Updates.cmd`，填入本次运行目录中 `update-state.clixml` 的完整路径，恢复本次操作前的更新服务/任务设置。若原先就禁用了更新，这个恢复不会猜测默认设置或自动替你启用。

本工具接受的安装包为 Windows x64 151.0.4129.107，SHA-256：
`B75F03B87DFB0CBC85BA2C0858C632511B17355F42563A43FCA5368100FFE0FE`。
还会检查有效微软数字签名。包不匹配就停止，不接受随意改名的其他版本。

## 边界与隐私

- 这是“双击入口”，不是无确认的静默工具。管理员确认、YES 确认和保存工作仍需要本人操作。
- 旧版浏览器有已知安全问题风险，回退可能丢失数据。只用于临时排查，Drop 不保证长期可用。
- 本地备份和日志保存在当前管理员账户的 Documents/EdgeRollbackLocal，包含敏感浏览资料，绝对不要上传。
- 只支持默认本地用户资料目录和常见系统级 Edge 路径。不覆盖定制用户目录、其他账户、企业托管环境或其他架构；使用其他管理员账户提权时应取消，回到原账户运行。
- 临时暂停已有的 MicrosoftEdgeUpdate* 任务及 edgeupdate/edgeupdatem 服务；不删除更新器、缓存、注册表或用户资料，不承诺阻止所有手动/企业更新入口。安装器可能重新配置更新组件。
- 不强制关闭浏览器，不自动重启计算机，不自动启动浏览器或上传任何资料。
- 两个启动文件只对本次 PowerShell 进程设置执行策略，不修改全局策略；组织强制策略仍可能阻止执行。
- 成功标准为安装退出码 0/3010 且实际文件为 151，不能只看退出码。本机已经验证过相同重装参数，但这个新工具尚未进行真实系统安装端到端测试。
- 不把待更新备份当作浏览数据恢复包；不要随意覆盖新旧版本的用户资料。
